# Smart College Portal

Прототип портала колледжа на Django: расписание с числителем и знаменателем,
замены пар, домашние задания и две AI-функции на Gemini — распознавание
расписания по фото и чат-помощник, который отвечает только про колледж.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # впишите GEMINI_API_KEY
python manage.py migrate
python manage.py seed_demo         # демо-группа, расписание, замена, задания
python manage.py runserver
```

Откройте http://127.0.0.1:8000 и войдите:

| Логин     | Роль          | Пароль      |
|-----------|---------------|-------------|
| `student` | студент ПО-21 | `demo12345` |
| `teacher` | преподаватель | `demo12345` |
| `admin`   | админка       | `demo12345` |

Чтобы показать с телефона, запустите `python manage.py runserver 0.0.0.0:8000`
и откройте на телефоне адрес компьютера в той же Wi-Fi сети.

Без `GEMINI_API_KEY` всё, кроме двух AI-функций, работает; чат и загрузка фото
покажут понятную ошибку. Ключ берётся в https://aistudio.google.com/apikey.

## Что где лежит

| Файл | Что внутри |
|------|------------|
| `portal/models.py` | `User` с ролями, `Group`, `Subject`, `ScheduleItem`, `Homework` |
| `portal/utils.py` | `get_week_type()` — числитель/знаменатель; сборка расписания с заменами |
| `portal/ai_services.py` | оба AI-модуля, системные промпты, проверка ответа модели |
| `portal/views.py`, `portal/urls.py` | развилка по ролям, кабинеты студента и преподавателя |
| `portal/forms.py` | формы замены, задания и загрузки фото |
| `portal/knowledge/college.md` | база знаний чат-бота (сейчас демо-текст) |
| `portal/tests.py` | 34 теста, идут без интернета и ключа: `python manage.py test` |
| `config/settings.py` | начало семестра, звонки, модели Gemini, лимиты чата |

## Как это устроено

**Роли.** После входа `/` отправляет студента в `/student/`, преподавателя в
`/teacher/`. Декораторы `student_required` и `teacher_required` закрывают чужие
страницы. Преподаватель видит только группы, привязанные к нему в админке
(«Пользователи» → «Группы преподавателя»); чужая группа отдаёт 404.

**Числитель и знаменатель.** Недели чередуются от первой учебной
(`SEMESTER_START`, её тип — `FIRST_WEEK_TYPE`). Счёт идёт по понедельникам,
поэтому чередование не сбивается на стыке годов.

**Замены.** Замена — это запись `ScheduleItem` с `is_replacement=True` и
конкретной датой. При показе она перекрывает постоянную пару с тем же номером
в этот день. Постоянное расписание при этом не меняется, поэтому замену можно
просто убрать.

**Расписание по фото.** Преподаватель загружает картинку → Gemini возвращает
JSON по схеме → Pydantic проверяет его → преподаватель видит таблицу и
подтверждает → постоянное расписание группы заменяется. Без подтверждения
база не меняется: модель может ошибиться в аудитории или типе недели.

**Чат-бот.** Отвечает только по `college.md` и данным студента (его пары и
задания). Защита от нецелевого расхода токенов:

1. системный промпт с жёстким правилом отказа одной фразой;
2. вопрос длиннее 500 символов отклоняется без обращения к модели;
3. не больше 15 вопросов за 10 минут с одного аккаунта;
4. потолок длины ответа и короткая история (3 последних обмена);
5. отказы не сохраняются в историю диалога.

## Перед показом

- Замените `portal/knowledge/college.md` на реальные сведения колледжа.
- Проверьте `SEMESTER_START`, `FIRST_WEEK_TYPE` в `.env` и `BELL_SCHEDULE`
  в `config/settings.py`.
- Прогоните обе AI-функции с настоящим ключом: в тестах вызовы Gemini
  подменены, с живым API код не запускался. Если модель из `.env` недоступна
  на вашем ключе, поменяйте `GEMINI_VISION_MODEL` и `GEMINI_CHAT_MODEL`.

## Ограничения прототипа

- Подгруппы не поддерживаются: в одном слоте (день, пара, тип недели) одна пара.
- Лимит запросов к чату хранится в памяти процесса и сбрасывается при перезапуске.
- SQLite и `DEBUG=1` — только для демо.
